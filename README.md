# Village Election Management System

A web-based Village Election Management System developed using Python and Django.

## Live Demo
https://village-election-management-system.onrender.com

## Features
- User Registration and Login
- Voter Management
- Candidate Management
- Village Management
- Online Voting
- Duplicate Vote Prevention
- Election Statistics
- CSV Report Downloads

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite
